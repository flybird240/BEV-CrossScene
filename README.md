## 系统功能

**一、跨交通场景重建BEV视图**

    (1) 场景区域设定：在道路边缘选取一个点，用户可输入感兴趣区域的长度（一般100-150米）和宽度(单车道3.75米)，绿色掩膜直观显示。
	    注意，选点可多试几次，尽量多且全的覆盖道路区间。
	
	(2) 场景对应点设置：在场景1和场景2中，至少选取三对对应点，为了做三维坐标系统一变换用。
        注意，每对对应点x值相同(平行于y轴即与道路方向平行)，尽量靠近相机监控点。
	
	(3) 跨场景BEV生成：将场景1和场景2中选取的感兴趣区域及盲区进行拼接，生成的BEV图是一个物理场景等比例尺图。
        注意，除了生成BEV图外，还获得场景1到场景2的三维变换旋转矩阵R和平移t。
	
	(4) 交互验证：在场景1和2中选点，在BEV视图中映射，以验证重建的准确率。
        注意，场景2中选点是其对应物理点的直接映射，场景1中选点多了一步三维坐标系变化。


## 说明

1）场景图像+标定文件需以文件夹形式放入至traffic_scenes_dataset文件夹下。

2）重建BEV视图时产生的文件是SetMarkDict.json，记录感兴趣区域的四顶点像素/物理坐标，及坐标变换对应点。注意，每个场景都有一个此文件。
